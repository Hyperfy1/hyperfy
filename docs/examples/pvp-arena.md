# PvP Arena Example

`/examples/pvp-arena.js` is a minimal, non-graphic melee sparring example. Add it as an app script in a world to create a walled arena; press **F** to swing. Attacks are handled by the server, limited by range, facing direction, and cooldown. Hits reduce the target's existing health, push them back, and respawn them after a knockout.

This example is not an age gate or an official age rating. Hyperfy worlds can contain user-created content, and this code does not verify anyone's age. World operators must assess their content and pursue any applicable rating or age-restriction process themselves.
